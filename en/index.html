Your whole Git workflow, from the keyboard

Commit graph

Streamed, virtualized history: hundreds of thousands of commits show up instantly, with branches and tags on every row.

Line staging

Stage, unstage or discard a file, a hunk or a single line. Unified or side-by-side diff with syntax highlighting.

3-pane conflicts

Resolve merges with the base (diff3) in view. Interactive rebase: reorder, squash, fixup, edit.

Undo / redo

Ctrl+Z after a bad commit, reset, merge or rebase. Gitlo puts the repository back the way it was.

Built-in Git Flow

Features, releases, hotfixes: start, publish, finish through a pull request or locally. Compatible with the git-flow extension.

Integrated terminal

A real shell under each repository (Ctrl+J): PowerShell, cmd, Git Bash, bash or zsh, in your theme colors.

GitHub, GitLab, Gitea…

Pull / merge requests, CI/CD with logs, issues linked to branches, clone from your account. Also Bitbucket, Azure DevOps and self-hosted servers.

Blame, bisect, reflog

Search history (message, author, content), file history, submodules and worktrees.

15 themes

Kraken Night, Dracula, Tokyo Night, Catppuccin, Nord, Gruvbox… Pick a dark and a light theme that follow your system.
