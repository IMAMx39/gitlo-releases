Keyboard shortcuts

Every Gitlo command is available from the keyboard.

On macOS, Ctrl becomes ⌘. Commands without a shortcut are available from the command palette (Ctrl Shift P).

Integrated terminal

Inside the terminal, Ctrl + letter goes to the shell, so Ctrl C interrupts the running command. Gitlo’s own shortcuts still work: Ctrl J, Ctrl Shift + letter, Ctrl + digit and Ctrl Tab.

ActionShortcut
CopyCtrl Shift C (⌘ C on macOS)
PasteCtrl Shift V (⌘ V on macOS)
