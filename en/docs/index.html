Getting started

Install Gitlo, open your first repository and take a tour of the interface.

Gitlo’s interface is in French for now. This guide gives each label as it appears in the app, followed by a translation.

Requirements

Gitlo runs the git binary installed on your machine, so it uses your existing config, hooks, credential helper, SSH, GPG and Git LFS. Make sure git is on your PATH:

git --version

If it is missing, Gitlo tells you at startup.

Install

SystemFileNotes
WindowsGitlo-Setup-x.y.z.exePer-user install, no admin rights needed. Updates automatically.
macOSGitlo-x.y.z.dmgDrag Gitlo to Applications. The app is unsigned: on first launch, right-click › Open.
LinuxGitlo-x.y.z-linux-x64.tar.gzUbuntu 20.04 / Debian 11 or newer. Extract the archive, then run gitlow. Requires libsecret.

Open a repository

  • Ouvrir (Open, Ctrl O): pick the folder of an existing repository.
  • Cloner un dépôt… (Clone) and Nouveau dépôt… (New repository) are in the command palette (Ctrl Shift P).
  • Once you connect a GitHub, GitLab or Gitea account, you can also clone straight from it.

Each repository opens in its own tab. Tabs and recent repositories come back the next time you launch Gitlo.

The interface

  • Sidebar: local and remote branches (grouped into folders for feature/…), tags sorted by version, remotes, stashes, submodules and worktrees.
  • History (Ctrl 1): the commit graph with branches and tags, plus details for the selected commit (files and diff).
  • Changes (Ctrl 2): staged, unstaged and untracked files, and the commit box.
  • Pull requests (Ctrl 3) and CI (Ctrl 4), once you connect a hosting account.
  • Terminal (Ctrl J): a shell opened in the repository folder.

On macOS, use ⌘ instead of Ctrl in every shortcut.

Your first commit

  1. In Changes, select a file and press Space to stage it. You can also stage a single hunk, or even a single line, from the diff.
  2. Type your message in the commit box.
  3. Press Ctrl Enter to commit. If you made a mistake, Ctrl Z undoes the commit.
  4. Push with Ctrl Shift U.
