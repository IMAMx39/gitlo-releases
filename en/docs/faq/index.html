FAQ and troubleshooting

Common questions, updates and how to report a problem.

Gitlo says git cannot be found

Install Git (git-scm.com), check that git --version works in a terminal, then restart Gitlo.

How do I update Gitlo?

Gitlo checks for new versions at startup and shows a banner when one is available. On Windows, click Installer et redémarrer (Install and restart). On macOS and Linux, the banner opens the download page. Update settings are in Paramètres › Mises à jour (Settings › Updates).

macOS won’t open the app

The app is not signed yet. In Applications, right-click Gitlo › Open, then confirm.

My repository is huge and history is slow

Above 10,000 commits, Gitlo offers to generate the commit-graph (palette › Optimiser le dépôt (commit-graph)). On the Flutter SDK repository (90,000 commits), this takes the first page of history from 669 ms down to 58 ms.

I made a mistake (reset, commit, merge…)

Ctrl Z undoes the last action: commit, amend, checkout, branch operation, merge, cherry-pick, revert, rebase, reset or pull. The Reflog (in the palette) also lists every past position of HEAD.

Is the interface available in English?

Not yet: Gitlo’s interface is in French.

Report a problem

Paramètres › Diagnostic (Settings › Diagnostics) shows the local log and lets you copy a report, with identifiers and tokens masked. Attach it to an issue on GitHub.
