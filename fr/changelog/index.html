Nouveautés

Les notes de chaque version de Gitlo.

  1. v0.1.9 5 octobre 2026 
    💻 Terminal intégré (Ctrl+J)
   Un vrai terminal sous chaque dépôt, ouvert dans son dossier :
   PowerShell, cmd, Git Bash, bash ou zsh, au choix dans
   Paramètres › Terminal.
   Couleurs du thème, copier / coller avec Ctrl+Shift+C / V,
   et l'historique se met à jour après vos commandes git.
   Le shell continue de tourner quand vous masquez le panneau.

🍵 Gitea
   Déclarez votre serveur Gitea dans Paramètres › Comptes :
   pull requests, issues, clone depuis votre compte, statut CI
   des commits et runs Gitea Actions (lecture seule).

🔐 Cloner un dépôt privé en HTTPS
   Saisissez votre identifiant et votre mot de passe (ou jeton)
   au moment du clone : git les garde pour les fetch et push
   suivants.

  2. v0.1.8 2 octobre 2026 
    ⚙️ CI/CD intégrée (Ctrl+4)
   Vos runs GitHub Actions et pipelines GitLab directement dans Gitlo :
   liste des exécutions, jobs, et log de chaque job.
   Le log s'affiche comme sur GitHub : étapes repliables avec leur
   statut et leur durée, erreurs en rouge, liens cliquables.
   Relancez les jobs en échec ou annulez un run en cours.
   Rafraîchi automatiquement tant qu'un run tourne.
   Un clic sur la pastille CI d'un commit ouvre son run.

🏢 GitHub Enterprise et GitLab auto-hébergé
   Déclarez le serveur de votre entreprise dans
   Paramètres › Comptes : pull requests, CI, issues et clone
   fonctionnent comme sur github.com et gitlab.com.

🐛 Corrections
   Créer une pull request vers une branche pas encore poussée
   (develop après l'initialisation Git Flow) propose maintenant
   de la publier d'abord.
   Les erreurs de GitHub indiquent le champ en cause.

    🎨 Thèmes
   15 palettes au choix : Kraken Night, Dracula, One Dark, Tokyo Night,

   et la vue de fichier.

⚙️ Paramètres

  7. v0.1.3 29 septembre 2026 
    Nouveau : Git Flow intégré.
- Initialiser Git Flow (branches, préfixes, préfixe de tag), compatible avec l'extension git-flow
- Démarrer une feature, une release ou un hotfix (version proposée d'après le dernier tag)
- Publier la branche et proposer une pull request
- Terminer : merge local ou pull request, squash, tag, suppression des branches, push
- Reprise après un conflit, annulation en une fois (⌘Z / Ctrl+Z)
- Bouton « Flow » dans la barre d'outils, section Git Flow dans la barre latérale, commandes dans la palette

Corrigé : la version Linux démarre à nouveau sur Ubuntu 20.04 / Debian 11 et versions plus récentes.
