Tout le workflow Git, sans quitter le clavier

Graphe de commits

Historique en streaming et virtualisé : des centaines de milliers de commits s'affichent sans attendre, avec branches et tags sur chaque ligne.

Staging à la ligne

Indexez, désindexez ou annulez un fichier, un hunk ou une seule ligne. Diff unifié ou côte à côte, avec coloration syntaxique.

Conflits en 3 panneaux

Résolvez les merges avec la base (diff3) sous les yeux. Rebase interactif : réordonner, squash, fixup, edit.

Annuler / refaire

Ctrl+Z après un commit, un reset, un merge ou un rebase raté. Gitlo remet le dépôt dans son état précédent.

Git Flow intégré

Features, releases, hotfixes : démarrer, publier, terminer par pull request ou en local. Compatible avec l'extension git-flow.

Terminal intégré

Un vrai shell sous chaque dépôt (Ctrl+J) : PowerShell, cmd, Git Bash, bash ou zsh, aux couleurs du thème.

GitHub, GitLab, Gitea…

Pull / merge requests, CI/CD avec logs, issues liées aux branches, clone depuis votre compte. Aussi Bitbucket, Azure DevOps et les serveurs auto-hébergés.

Blame, bisect, reflog

Recherche dans l'historique (message, auteur, contenu), historique d'un fichier, submodules et worktrees.

15 thèmes

Kraken Night, Dracula, Tokyo Night, Catppuccin, Nord, Gruvbox… Un thème sombre et un clair, qui suivent le système.
