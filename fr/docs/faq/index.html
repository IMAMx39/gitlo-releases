FAQ et dépannage

Questions fréquentes, mises à jour et signalement d'un problème.

Gitlo indique que git est introuvable

Installez Git (git-scm.com), vérifiez que git --version fonctionne dans un terminal, puis relancez Gitlo.

Comment mettre à jour Gitlo ?

Gitlo vérifie les nouvelles versions au démarrage et affiche un bandeau quand il en trouve une. Sous Windows, cliquez sur Installer et redémarrer. Sous macOS et Linux, le bandeau ouvre la page de téléchargement. Les réglages se trouvent dans Paramètres › Mises à jour.

macOS refuse d’ouvrir l’application

L’application n’est pas encore signée. Dans Applications, faites un clic droit sur Gitlo › Ouvrir, puis confirmez.

Le dépôt est très gros et l’historique est lent

Au-delà de 10 000 commits, Gitlo propose de générer le commit-graph (palette › Optimiser le dépôt (commit-graph)). Sur le dépôt du SDK Flutter (90 000 commits), le premier lot de l’historique passe ainsi de 669 ms à 58 ms.

J’ai fait une erreur (reset, commit, merge…)

Ctrl Z annule la dernière action : commit, amend, checkout, opération sur une branche, merge, cherry-pick, revert, rebase, reset ou pull. Le Reflog (dans la palette) affiche aussi toutes les positions passées de HEAD.

L’interface est-elle disponible en anglais ?

Pas encore : l’interface de Gitlo est en français.

Signaler un problème

Paramètres › Diagnostic affiche le journal local et permet de copier un rapport, dans lequel les identifiants et les jetons sont masqués. Joignez-le à une issue sur GitHub.
