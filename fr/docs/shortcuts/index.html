Raccourcis clavier

Toutes les commandes de Gitlo sont accessibles au clavier.

Sous macOS, Ctrl devient ⌘. Les commandes sans raccourci se lancent depuis la palette (Ctrl Shift P).

Terminal intégré

Dans le terminal, Ctrl + lettre est envoyé au shell : Ctrl C interrompt la commande, par exemple. Les raccourcis de Gitlo restent actifs : Ctrl J, Ctrl Shift + lettre, Ctrl + chiffre, Ctrl Tab.

ActionRaccourci
CopierCtrl Shift C (⌘ C sous macOS)
CollerCtrl Shift V (⌘ V sous macOS)
