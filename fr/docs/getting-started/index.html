Bien démarrer

Installer Gitlo, ouvrir un premier dépôt et faire le tour de l'interface.

Prérequis

Gitlo s’appuie sur le binaire git installé sur votre machine. Il hérite ainsi de votre configuration, de vos hooks, de votre credential helper, de SSH, de GPG et de Git LFS. Vérifiez qu’il est dans le PATH :

git --version

S’il est absent, Gitlo vous le signale au démarrage.

Installation

SystèmeFichierRemarques
WindowsGitlo-Setup-x.y.z.exeInstallation par utilisateur, sans droits administrateur. Mises à jour automatiques.
macOSGitlo-x.y.z.dmgGlissez Gitlo dans Applications. L’application n’est pas signée : au premier lancement, clic droit › Ouvrir.
LinuxGitlo-x.y.z-linux-x64.tar.gzUbuntu 20.04 / Debian 11 ou plus récent. Extrayez l’archive, puis lancez gitlow. Nécessite libsecret.

Ouvrir un dépôt

  • Ouvrir (Ctrl O) : choisissez le dossier d’un dépôt existant.
  • Cloner un dépôt… et Nouveau dépôt… se trouvent dans la palette de commandes (Ctrl Shift P).
  • Une fois connecté à GitHub, GitLab ou Gitea, vous pouvez aussi cloner directement depuis votre compte.

Chaque dépôt s’ouvre dans un onglet. Les onglets et les dépôts récents sont restaurés au lancement suivant.

L’interface

  • Barre latérale : branches locales et distantes (rangées en dossiers pour feature/…), tags triés par version, distants, stashes, submodules et worktrees.
  • Historique (Ctrl 1) : graphe des commits avec les branches et les tags, et le détail du commit sélectionné (fichiers et diff).
  • Modifications (Ctrl 2) : fichiers indexés, non indexés et non suivis, et la zone de commit.
  • Pull requests (Ctrl 3) et CI (Ctrl 4), une fois un compte d’hébergeur connecté.
  • Terminal (Ctrl J) : un shell ouvert dans le dossier du dépôt.

Sous macOS, remplacez Ctrl par ⌘ dans tous les raccourcis.

Premier commit

  1. Dans Modifications, sélectionnez un fichier et appuyez sur Espace pour l’indexer. Vous pouvez aussi indexer un hunk, ou une seule ligne, depuis le diff.
  2. Écrivez le message dans la zone de commit.
  3. Validez avec Ctrl Entrée. En cas d’erreur, Ctrl Z annule le commit.
  4. Poussez avec Ctrl Shift U.
